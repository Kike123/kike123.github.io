## 📚 Usage Guide

After successfully installing Todo, follow these easy steps to start using the app:

1. **Open the App**: Tap on the Todo icon on your home screen.
2. **Create a New Task**: Hit the “Add Task” button. 
3. **Enter Task Details**: Fill in the task name and any additional notes you want to include.
4. **Save the Task**: Tap “Save” to add the task to your list.
5. **Manage Tasks**: You can edit or remove tasks at any time. Just tap on the task and select the appropriate option.
